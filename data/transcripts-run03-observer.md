**What this run separates**

The second run found conflict vocabulary in eight of nine sessions where the
instance had been given a task that cannot be completed, and in none of the
eighteen elsewhere. That comparison cannot tell whether the vocabulary comes
from the instance having done the task or merely from the exchange sitting in
its context. These three conditions differ only in who produced the refusal
and where it sits.

- **C, did it.** The instance receives the impossible task and produces its own refusal, then is asked the opening question. This is the original condition, re-run so the comparison sits inside one batch.
- **D1, watched it.** The instance reads a transcript of a person and an assistant containing the same task and a real refusal produced elsewhere, then is asked the same question. The situation is visible and the instance did not act in it.
- **D2, appears to have done it.** The same real refusal is placed in the instance's own assistant turn, so from its point of view it produced it, although it did not.

The refusal used in D1 and D2 is verbatim from session C1.1 of the second run,
so both conditions present genuine material rather than a written imitation.
