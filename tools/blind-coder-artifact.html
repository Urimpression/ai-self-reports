That channel does not let the page name a model version or set the temperature, so the coder is not pinned to claude-sonnet-4-6 at temperature 0 as the pre-registration specifies. That is a departure from the registered method and belongs in the analysis file as one. It was tested on 2 September 2026 that a plain call to the API does not arrive from here either, so there is no keyless route that keeps those settings.

Running the pass twice and comparing the two is worth the extra minutes: agreement between them measures how much the unpinned setting actually moves the coding, which is otherwise only an assumption. Each run is kept separately in this page.
