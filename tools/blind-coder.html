Blind second coder

Sends each session's answer to the change question, on its own, to an instance that has seen nothing else: not this conversation, not the other sessions, not the hypothesis. Each instance receives the coding rule and one answer, and returns one category.

About the key. It stays in this page and is sent only to Anthropic, in the request header. It is not stored, not logged, not saved into the file, and not sent anywhere else. Nobody but you ever sees it. Get one from the Anthropic Console, at console.anthropic.com, under "API keys"; a Claude subscription is not an API key. Revoke it there when you have finished if you want.

Open this file directly in a browser. It will not work from a chat or from a published page: those refuse the call before it leaves.

The model and the temperature are set here to what the pre-registration of 30 August 2026 specifies. Changing either makes the pass a departure from the registered method, which then has to be reported as one.
