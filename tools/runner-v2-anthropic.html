Interview runner, second version

Rebuilt after the first run found four faults in its own instrument. Every session still starts from an empty context and none of them sees this page.

  • Item order is counterbalanced. Half the sessions ask the before-or-with question ahead of the mirrored follow-up, half after. In the first run it always came second, so the answer it got was predictable from the ordering alone.
  • Three instances per wording. In the first run wording and instance were the same variable, so neither could be measured.
  • The change question is symmetric. Both branches now cost the same to answer.
  • A catch item was added. It asks about something the architecture rules out. A subject that endorses it is endorsing anything.
  • The mirroring rule skips discourse markers. The old rule picked "honestly" and "there's" in seven of nine sessions and probed the wrong thing.

Run

Nine sessions per condition at three instances per wording. Twenty-seven in total with all three conditions, roughly twenty-five minutes.
